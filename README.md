# Masroof · مصروف

Masroof is a bilingual (Arabic / English) personal finance platform for tracking
accounts, categories, and transactions across mobile and web.

| App        | Path       | Stack                                                        |
|------------|------------|--------------------------------------------------------------|
| REST API   | `backend/` | Laravel · PostgreSQL · Redis · Sanctum · Queues · Scheduler  |
| Web        | `web/`     | Next.js · TypeScript · Tailwind CSS · TanStack Query         |
| Mobile     | `mobile/`  | Flutter · Riverpod · GoRouter · Dio · Drift                  |
| Branding   | `branding/`| Master icon source and generated brand assets               |
| Docs       | `docs/`    | Architecture, API, development guides                        |

Documentation lives in [`docs/`](docs/README.md).
